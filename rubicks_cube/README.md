# 3D Rubik's Cube Matrix (`rubicks_cube`)

Interactive 3D WebGL 3×3×3 Rubik's Cube simulator & auto-solver built with **Three.js (WebGL)**, **JavaScript**, and **Secured Extensionless PHP Routing**.

### Features
- **Real 3D Layer Rotations**: `U`, `D`, `L`, `R`, `F`, `B` 90° animated face turns
- **One-Click Scramble & Auto-Solver**: Reverses scramble history with smooth cubic-bezier easing
- **Move Counter, Live Timer & Drag-Orbit Camera**
